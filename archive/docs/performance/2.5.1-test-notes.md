# diskOS Disco 2.5.1 test candidate

Base: public main f4c7af680553a70b52a633eb0fd7a6b38c46a60a (fixed 2.5.0).
This is a device test candidate, not a published release. No GitHub push or physical-device test was performed.

## Included

- Simplified Squash volume: immediate player reports outside a drag/pending send, failed-send-only retry timer, smaller entrance/exit, animation-off respected. Disco and Null volume handling is unchanged.
- Clear the Squash Library jump-to-track fill when manual scrolling starts; retain Music return context.
- Album Wall: bounded background SD/decode/sprite preparation, generation checks on results, foreground-art priority, paused hidden prefetch, hidden cache trimming after a quiet 30 seconds, and freed seed snapshots.
- Prewarm queue waits for UI idle; covers-only mode remains supported. Visible Album Wall demand loading remains available.
- Per-thread nonblocking database readers, with UI reads inside the UI's own write transaction still using that transaction. Writes retain their existing policy.
- Allocate the secondary favourites/history song array only when used; retain public song structures and all data fields.
- Allocate large poster/immersive representations when needed and release cold immersive buffers after the closing animation. Existing timings remain, apart from the authorised Squash volume changes.
- Lossless compressed Roulette wheel (518400 pixel bytes become 45858 embedded bytes). No glyphs, themes, features or artwork formats removed.
- Roulette final screen has Play, then a pill-shaped Again/Exit row; Again reuses prepared covers. Theme colours and typography follow the app policy used by Stats; Play stays white/black. Rapid reopen no longer joins an unfinished loader on the UI thread.
- Track popup title and artist scroll indefinitely in Disco, Null and Squash, including forced restyling; Squash text is narrower. Music screen finite scrolling is unchanged.
- Playback > Library seeking: A-Z picker (default) or Letter wheel. Wheel mode places the current letter on the theme's scrollbar, opens on hold (also on tap), scrubs clockwise/counterclockwise, and confirms by centre tap or 1 second after release. New touches suspend the deadline. The overlay background is 50% opaque; text and centre control remain opaque. Null uses square controls; other themes circular controls. Centre typography follows the actual Music title font.
- About uses 2.5.1; the boot log identifies the version. Successful volume-send spam is debug-only; failures remain logged. Slow UI frames (150ms+) and unexpected artwork decode failures have 10-second log rate limits.
- Log size maintenance runs in a background thread every 30 seconds. Boot log target is 256 KiB; coldplug, volume-debug and SD-guard logs target 64 KiB each. Each retains one bounded `.1` copy. A failed backup leaves the live log intact; open append descriptors keep working. These are periodic soft limits, not hard byte quotas. Boomshine retains its existing per-launch temporary log behavior. The deployment helper appends instead of discarding previous boot evidence.

## Validation

- Native wheel interactions passed in Ring, Braun, Disco, Null and Squash, both appearances: legacy picker, real hold, clockwise/reverse, Z/#/A boundary, held-touch timeout suppression, centre/timeout commit, twelve repeated cancellations, and switching back to A-Z.
- Popup infinite-scroll checks passed in Disco/Null/Squash, both appearances, across two simulated minutes and forced restyling.
- Squash volume regression passed in both appearances, including rapid reopen, retry exhaustion/recovery, drag/release and clamps.
- Immersive rapid reopen passed for Disco/Null/Squash; normal exit passed for Ring/Braun.
- Real SQLite exclusive-lock test returns within 50ms, recovers, preserves read-your-writes in a transaction, and isolates worker readers.
- Existing artwork/cache/history contention and queue tests passed. SD guard tests passed with LeakSanitizer disabled because this execution environment cannot enumerate the sanitizer's process threads; no leak-check claim is made.
- Album Wall repeated enter/drag/leave, 30-second hidden trimming and reopen passed. Native Library manual-scroll test cleared the filled location marker.
- Roulette final controls/reroll/exit passed in Disco, Null and Squash.
- Every decoded wheel byte matches the original raw resource and source PNG.
- Log rotation test passed: bounded previous copy, repeated trimming, writing through an already-open descriptor, and failure preserving live data.
- Static MIPS device compile/link and theme checks passed. Hardware CPU, long-run RSS, audio stability and SD responsiveness still require testing on the Disc.

## Deliberately not included

Experimental font compression and replacing the public fixed-size song records with interned strings remain benchmark/design candidates, not established safe fixes. The test build keeps every font and the existing song API. Lazy allocation of the duplicate history/favourites array addresses an immediate RAM cost without that redesign.
