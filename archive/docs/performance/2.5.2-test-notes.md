# 2.5.2 validation

Native LVGL checks cover fresh/default migration, track-popup horizontal scrolling in all three themes and both appearances, opaque letter rings, Roulette Again/Exit and repeated spin/exit/reopen, Squash volume, Quick Settings EQ, disabled Accent and Wi-Fi/Bluetooth controls. Working mode and Shortcuts were rendered in dark and light Squash; all five mode labels fit and the root cannot scroll.

Config, playback-state, file-operation, shortcut and queue regressions passed. Artwork responsiveness and decoder tests passed. A dedicated ASan/UBSan decoder test covers allocation limits, cancellation, recovery and concurrent normal/Roulette requests. Roulette lifecycle checks verify descriptors and covers are detached and released after leaving, including repeated cancellation/reopen.

Website JavaScript syntax, local assets/anchors and mocked chapter layout/reduced-motion behaviour passed. Real browser QA was unavailable. Sanitizer runs disable LeakSanitizer because this container cannot inspect process task mappings; decoder tracked allocations are checked explicitly.

These are host checks, not a physical Disc endurance or performance measurement. On-device memory, playback stability, gesture feel and visual quality still need testing with the supplied mq_ui.
