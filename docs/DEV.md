# Development status

`dev` is experimental and takes all new work. Merging to `main` and tagging are maintainer-only. Source changes after a release aren't in that release's payload.

See [workflow](DEV_WORKFLOW.md), [branch and release rules](DEVELOPMENT.md), [targets](../todo.md) and the [3.6.1 binary record](RELEASE_3.6.1.md). Archived performance notes are historical, not claims about current builds.
