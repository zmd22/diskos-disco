# Quick reference

| Task | Where / how |
|---|---|
| Choose a theme | Settings > Display > Theme |
| Change light/dark | Display > Light / dark, where supported; Null stays dark |
| Set Wheel lists | Display > selected theme settings > Navigation > List motion |
| Choose letter navigation | Playback > Library seek: A-Z keys / A-Z wheel |
| Change album presentation | Display > Library appearance |
| Change Music appearance | Display > selected theme settings > Music screen, where available |
| Configure Immersive | Display > Immersive |
| Choose Shade | Display > QS style > Shade |
| Configure QS items / shortcuts | Display > Navigation |
| Configure theme menu / gestures | Display > selected theme settings > Navigation |
| Set standby delays | Battery & power > Screensaver delay / Screen-off delay |
| Set sleep timer | Battery & power > Sleep timer |
| Configure online artwork / lyrics / weather | Connectivity > Online services |
| Change clock format | System > Date & Time |
| Read version / build ID | Help > About |
| Update from SD | System > Maintenance > Update from SD Card |
| Restore contextual hints | Help > Show hints again, on supported themes |

- Track actions: tap the Music title (Disco, Null, Squash). Context menu: hold a library item.
- **Queue** is your explicit up-next list; **Up Next** is the player's current playback context.
- Disc Shelf, SongSphere, Album Roulette, Listening Stats and Boomshine are built in.
- Controls that don't apply to the current firmware or theme are hidden or disabled.

See the [tour](DISCO_TOUR.md), [settings](DISPLAY_SETTINGS.md) and [Disc Shelf](DISC_SHELF_INSTALL.md).
