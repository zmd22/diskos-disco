# Disco! 3.4.4

## Battery life back to 3.4.1

3.4.2 stored Disco's large fonts (32 px and up) in a compressed format to make the interface smaller. The Disc then
had to unpack every big letter each time it was drawn, many times a second while a long title scrolls on Now Playing
or a large clock is on screen. That cost battery.

3.4.4 stores those fonts uncompressed again. Everything looks exactly the same, Cyrillic in Zune included; the
interface is about 790 KB larger, close to 3.4.1's size. Nothing else changes from 3.4.3.

Binary record: [RELEASE_3.4.4.md](../RELEASE_3.4.4.md). Update from the SD card as usual
([guide](../UPDATING.md)); no reflash.
