# diskOS Disco! 2.7.0

**Your music, to go.** Disc Shelf joins the firmware, with Navidrome and SMB3 downloads in the same themed interface.

## Bring your collection along

- Disc Shelf is built in; no separate app installation is needed.
- Pick Navidrome for artists/albums/tracks, or SMB3 for a simple folders-and-files browser. Only one source connects at a time.
- Familiar library rows, swipe-to-select, Download-only actions, position dots, the A–Z grid and letter circle work across Disco, Null and Squash.
- Finish partial albums or folders with Missing only. Download again replaces only matching copies owned by Disc Shelf; unrelated files are kept. Completed files survive cancellation.
- A jewel-case CD icon, compact headers, wider rows and scrolling selected names make the app fit the round screen.
- New Navidrome files use `Artist/YYYY - Album/NN. Track name.ext`, without a routine identifier suffix. Unknown years become `0000`; collision suffixes protect existing files. Existing downloads are not renamed, and SMB names stay as on the share.
- Downloads show three lines of description, a smaller percentage with smoothed speed, and a larger MiB counter.

## Hold. Shuffle. Listen.

Choose **Shuffle!** under **Display > Navigation > Gestures > Menu hold**. It starts the full song library using the same shuffle path as Library, takes you to Music and shows a themed **“Happy listening!”** popup. Existing assignments keep their meanings. The common action picker also offers it for menu double-tap.

SongSphere now has a themed guard screen matching Disc Shelf: browse past it freely and press **Open SongSphere** when ready. Direct track/album/artist Mood editors remain immediate.

Squash Settings headings now align better with the back arrow, with the arrow slightly further inward.

## Less unnecessary work

- During Navidrome/SMB3 copies, Wi-Fi power saving is temporarily disabled if enabled, then its exact previous mode is restored on completion, cancellation or error. Already-disabled power saving is left alone. Unsupported driver commands do not block copying; restoration is best-effort if the radio/driver disappears. No permanent preference is changed.
- No Disc Shelf background sync, discovery or full-library rescan. The backend connects only after opening the app and waits when idle.
- Navidrome batches small writes in a temporary 128 KiB buffer, reducing write calls by about 75% in a localhost test. **An actual transfer-speed or battery improvement on the Disc has not been measured.** Resource checks, cancellation, byte/media validation and final file synchronization remain.
- Guard screens are static: browsing them opens no app database, worker or animation engine.

## Privacy and compatibility

Fresh profiles keep passwords for the app session only. Remember password On saves readable credentials in a private file, **not encrypted storage**. Existing Navidrome configs remain compatible. Navidrome now uses salted tokens, which are still reusable credentials; use HTTPS and keep authenticated URLs private.

SMB3 requires encrypted transport and does not fall back to SMB1/2. **SMB3 remains experimental.** Encrypted host wire tests passed, but independent physical NAS/Disc compatibility, peak memory/current draw and hot-card removal remain unverified. Navidrome has been used successfully on the owner’s Disc. These results do not guarantee every server or card will work.

The normal firmware install/update paths are unchanged. The 1.0.4 standalone Disc Shelf archive remains a legacy download for older firmware and is not needed on 2.7.0. No Bluetooth, power-button or upstream-settings migration changes were added relative to public 2.6.2.

## Updating
