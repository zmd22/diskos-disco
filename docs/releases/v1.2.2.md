# diskOS Disco! 1.2.2

Album Roulette now ships as a separate user app alongside mq_ui, rather than
being embedded in the firmware executable. The main-menu vinyl icon, themed
landing screen, Apps/shortcut routing, smooth scrolling and other UI changes remain.

Download the complete release ZIP for mq_ui, apps/album-roulette, installation
instructions and corresponding app source. Install both components as described
in INSTALL.md. A signed UI-only update no longer installs or updates Roulette.
Existing app installations and settings are not modified by firmware startup.

Album Roulette 1.3.1 includes the memory fix: shared fallback artwork, a bounded
uncached-image heap, and destination allocation deferred until after decoding.
The 37-album pool and decoder safety guards remain. Low available RAM can still
result in placeholders; this prevents placeholder allocations accumulating until
preparation aborts.

Validation: production MIPS build and theme gate passed; the focused 37-cover,
three-cycle low-memory regression passed. Physical-device verification remains
necessary. Existing owner signing keys are required for SD-card UI updates.
