# Disco! 3.3.1

**Fixed:** changing List motion now updates the main Settings menu in Squash, Disco and Null. Switching away from Wheel clears its row scaling, spacing and snap scrolling. Returning without changing the setting keeps the menu's scroll position.

Documentation now describes the shipped Braun 2.0 layouts and native Disc Shelf. The complete ZIP includes current guides and licences with checked document links. Stale Braun render sheets were removed; three representative previews remain.

This release includes a fresh static MIPS build of the matching UI source. The Settings regression fails on the previous code and passes in Squash light/dark, Disco and Null. Physical-device validation of this binary has not been performed.
