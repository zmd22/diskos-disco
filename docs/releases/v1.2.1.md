# diskOS Disco! 1.2.1

**Album Roulette is now included, not just linked from the menu.**

This patch release includes all 1.2.0 scrolling, navigation, Quick Settings and landing-page improvements,
and bundles Album Roulette 1.3.0 inside the compiled `mq_ui`. It therefore arrives with fresh firmware installs
and normal UI-only updates, including signed updates made with your owner keys.

On startup, missing app files are installed under `/usr/data/apps/album-roulette`. An existing executable and
configuration are preserved. The app does not auto-launch. Select Album Roulette from the main menu, Apps or
shortcuts, tap **I feel lucky!**, then **Surprise me** to spin your local album collection.

Round covers fly past and settle on a winner. Tap Play! or the cover to start the album; hold the cover to return
for another spin. Albums with fewer than four indexed tracks are excluded. See the
[tour](https://github.com/zmd22/diskos-disco/blob/main/docs/DISCO_TOUR.md#album-roulette).

The app's complete corresponding source and dependency licenses are included under `corresponding-source/`.
The larger mq_ui contains the app; installation writes a separate approximately 3.8 MiB app executable to user
storage only when missing. Normal launches do not rewrite an existing app.

App/UI compilation, the theme gate and a focused host installation check passed. No final physical-device test
was performed here. Use the existing installation/update guides; owner signing keys are still required for
signed SD-card update packages.
