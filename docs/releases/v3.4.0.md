# Disco! 3.4.0

> [!TIP]
> **No reflash needed.** 3.4.0 is an ordinary SD-card update from 1.4.1 or later, aptX included: everything, the
> optional aptX files too, comes inside the signed `mq_ui`. Sign it with your usual keys, copy the six files to
> `<SD>/diskos-update/`, then Settings › System › Maintenance › Update from SD Card.

**New: Bluetooth codec badge.** Song Info shows the output and the codec your headphones are really using, for
example *Bluetooth · LDAC*.

**New: aptX and aptX HD (experimental, off by default).** Turn on Settings › Connectivity › **aptX (experimental)**,
then turn Bluetooth off and on: with Bluetooth Codec on Best, aptX headphones then use aptX HD or aptX. The first connection after turning it
on can still use SBC while Disco learns your headphones' codecs; from the next connection on, aptX is used. It uses an open-source aptX encoder
(libfreeaptx) with BlueALSA 4.0.0, built for the Disc and carried inside Disco. Off, Bluetooth is FiiO's, exactly as
in 3.3.1.

**Better: the best codec your headphones offer.** Bluetooth Codec is now SBC, AAC or **Best** (with the LDAC
quality: Mobile, Standard or High). Best uses LDAC or aptX, whichever the headphones have, and only then AAC, then SBC:
LDAC → aptX HD → aptX → AAC → SBC (aptX steps only with aptX on). LDAC and aptX headphones each get their own best codec
without changing the setting, and a codec that doesn't get through steps down to the next one.

**Fixed:** headphones could get stuck on AAC: one slow codec switch marked LDAC (or aptX) as failed for good, and
from then on Disco never saw it again. A codec that doesn't come up now only steps down for that one connection, and
the codec memory only ever grows. Pairs stuck on AAC recover on their own after the update.

**New: crash guard.** If the Disc restarts just as music starts on a codec that hasn't played on those headphones
before, that codec is skipped for them, and Disco says so. Choosing Bluetooth Codec again gives it another try.

**With aptX on,** LDAC always runs on FiiO's own Bluetooth audio, and Disco's aptX build only does aptX / aptX HD
(LDAC through it froze the Disc in testing). Headphones are reconnected once, briefly, when their best codec needs the
other one.

**Installers:** a new Linux app (Check, Install, Update, Restore), Fedora and Arch packages with the flash tools
included, and the Windows app redone with the same tabs. Update works on its own, without an install from that PC.
The standalone Disc Shelf archive is no longer packaged (it is built in since 3.2.0; 3.3.1 has the last copy).
