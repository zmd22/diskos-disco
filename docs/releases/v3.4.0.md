# Disco! 3.4.0

## aptX comes to the Disc (experimental)

**aptX and aptX HD on the Snowsky Disc.** FiiO's Bluetooth stack on the Disc has SBC, AAC and LDAC only. Disco 3.4.0
carries its own open-source aptX Bluetooth audio (BlueALSA 4.0.0 with the libfreeaptx encoder, built for the Disc)
inside the interface, so aptX headphones such as the Sennheiser Momentum True Wireless 4 can play aptX, and aptX HD
headphones aptX HD.

Turn on **Settings › Connectivity › aptX (experimental)**, choose a **Bluetooth Codec** starting with *aptX/LDAC*,
then turn Bluetooth off and on. Off (the default), Bluetooth is FiiO's, as in 3.3.1.

> [!WARNING]
> **Experimental.** All of this release's Bluetooth codec handling is experimental: aptX, the codec choice, the
> automatic switching between Bluetooth stacks, the crash guard and Quiet Wi-Fi for Bluetooth. It was tested on one
> Disc with two pairs of headphones (an LDAC pair and an aptX pair). Expect rough edges, such as pressing Play again
> after changing headphones. aptX Adaptive and aptX Lossless are not supported (there is no open encoder for them).

## Bluetooth

- **Codec choice: aptX/LDAC.** Bluetooth Codec is SBC, AAC or **aptX/LDAC Mobile / Standard / High**. aptX/LDAC uses
  LDAC or aptX, whichever the headphones have, then AAC, then SBC: LDAC → aptX HD → aptX → AAC → SBC. The quality is
  LDAC's. LDAC and aptX headphones each get their best codec without changing the setting.
- **LDAC always runs on FiiO's own Bluetooth audio**, and Disco's aptX build only does aptX / aptX HD: LDAC through it
  froze the Disc in testing. When a pair's best codec needs the other one, Disco reconnects it once, briefly.
- **Codec badge:** Song Info shows the output and the codec really in use, for example *Bluetooth · LDAC*.
- **Fixed: headphones stuck on AAC.** One slow codec switch could mark LDAC (or aptX) as failed for good. A codec
  that doesn't come up now only steps down for that connection, and the codec memory only grows. Pairs stuck on
  AAC recover on their own.
- **Crash guard:** if the Disc restarts just as music starts on a codec that hasn't played on those headphones
  before, that codec is skipped for them and Disco says so. Choosing Bluetooth Codec again gives it another try.
- **Quiet Wi-Fi for Bluetooth** (Settings › Connectivity, on by default): Wi-Fi and Bluetooth share one radio on the
  Disc. While you listen over Bluetooth, Wi-Fi saves power and stops searching for networks, so the headphones get
  more airtime: fewer dropouts, LDAC above all. Wi-Fi still works.

More in the [Bluetooth guide](../BLUETOOTH.md).

## Installers (experimental)

- **New Linux app** with the Windows app's tabs: Check, Install, Update and Restore, each usable on its own. Fedora
  (`.rpm`) and Arch (`.pkg.tar.zst`) packages include the flash tools and USB access. [Linux guide](../LINUX.md)
- **Windows app redesigned** with the same tabs (Check, Setup, Install, Update, Restore). Update works on its own,
  without an install from that PC. [Windows guide](../WINDOWS.md)
- The standalone Disc Shelf archive is no longer packaged (built in since 3.2.0; 3.3.1 has the last copy).

## Updating

> [!TIP]
> **No reflash needed.** 3.4.0 is an ordinary SD-card update from 1.4.1 or later, aptX included: the optional aptX
> files come inside the signed `mq_ui`. Sign it with your keys, copy the six files one by one to `<SD>/diskos-update/`,
> then Settings › System › Maintenance › Update from SD Card.

This release includes a fresh static MIPS build of the matching UI source. Its source was tested on a Disc as signed
test builds; this exact binary differs from the last one only in its version and codec labels.
