A new look. A shared effort.

Credit where
it belongs.

Thank you, namastecoconut-imagined.

The Zune theme began with namastecoconut-imagined’s Zune fork: its Metro-inspired visual direction, expressive typography, dark canvas, home menu and distinctive music and library presentation. That design and implementation are the foundation of what you see here.

We adapted the theme into Disco’s shared controls and features, retaining its character. Please visit the original author’s work and give them the credit for the idea.

A little extra polish.

zmd22’s pass focuses on readability and everyday use: larger small text, more balanced spacing, clearer confirmations, configurable shortcuts, a new accent-coloured volume overlay and shared library views.

Built on b0hemia’s diskOS and the work of its contributors, with LVGL and Open Sans. Open Sans keeps its SIL Open Font License. Full acknowledgements and licences.

An unofficial fan theme; not affiliated with Microsoft. Thanks to everyone who builds, tests and shares improvements for this little player.

Used the Windows app before? Set it up again once.

Download the latest Windows app below, open it and click Set up again on its setup page. Until then, an older app keeps installing the version it was first set up with. From 2.5.9 on, the app also updates itself to the latest release on every start.

Made for FiiO firmware V2.57. Start from FiiO’s stock V2.57 firmware: installing over upstream diskOS or another diskOS build is not supported and can be buggy. Switched from upstream diskOS and something looks wrong? Settings › System › Maintenance › Reset diskOS Settings. Starts stock after installing? Hold Volume Up at power-on, then Settings › System › Controls › Default UI › diskOS. Back up your player before you begin.
