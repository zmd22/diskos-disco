Before you install · compatibility and recovery

Made for FiiO firmware V2.57. Start from FiiO’s stock V2.57 firmware: installing over upstream diskOS or another diskOS build is not supported and can be buggy. Switched from upstream diskOS and something looks wrong? Settings › System › Maintenance › Reset diskOS Settings. Starts stock after installing? Hold Volume Up at power-on, then Settings › System › Controls › Default UI › diskOS. Back up your player before you begin.
